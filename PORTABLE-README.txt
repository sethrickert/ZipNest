ZipNest portable
================

1. Keep the ZipNest folder together; the included 7zip folder is required.
2. Run ZipNest.exe to choose the default double-click mode and optional Explorer integration.
3. Or drag one or more ZIP, 7z, or RAR archives onto ZipNest.exe.

Portable settings stay beside the application in settings.ini. Explorer integration stores the
current ZipNest.exe path, so remove the integration before moving or deleting this folder.

ZipNest stays quiet on success. It only opens a window for passwords, settings, or errors.
